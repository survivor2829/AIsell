# 宋体标题字体（songti_v5）

`narration-serif.ttf` 由 Noto Serif SC 2.002 可变字体（© 2017-2023 Adobe，SIL Open Font License 1.1，源自 https://github.com/notofonts/noto-cjk ）用 fontTools 固定为 900 字重，并裁成 GB2312 汉字、ASCII 与常用中文标点。OFL 允许修改后再分发；许可全文随运行时以 `narration-font-OFL.txt` 提供。

说明放在这里而不是 `../LICENSES.md`：那个文件会打进安装底座，改它会触发底座升级检查。
