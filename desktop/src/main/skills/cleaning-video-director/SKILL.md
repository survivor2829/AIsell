# 清洁设备视频导演

本 Skill 由 **叶镜川·产品效果导演** 与 **数字人口播导演** 共用。前者负责设备、场景和镜头，后者负责人物、语言和声音。应用运行时使用同目录的 `rules.cjs`；修改规则后须同步核对本说明及旧任务的版本兼容。

## 输入与证据

- 产品片输入：一张产品原图、产品名称、卖点与参数资料（可粘贴或导入UTF-8 TXT）、时长和费用上限；从资料推荐最多三个场景，也可手动选择。口播另需已授权的人物参考图、完整文案和声音风格。
- 将照片中可见的外观、用户填写但尚待核实的产品事实、已核实资料分开记录。资料不足时只拍外观和场景，不模拟清洁效果、参数或客户证言。
- 人物参考只能用于用户已授权的数字人任务。保持脸、年龄、发型和肤色自然一致；不得改造身份、磨成塑料皮肤或凭空生成真实人物背书。

## 输出合同

先给用户可确认的方案，再提交付费任务。方案包含：

1. **概念与观众**：谁会看、现场问题是什么、希望对方看完采取什么行动。社媒开头用真实问题吸引注意，不保证“爆款”。
2. **视觉方向**：产品外观锚点、人物参考、场景和材质；暖冷关系、自然肤色、白平衡、主光/补光/轮廓光与阴影方向。
3. **摄影参数**：9:16，源视频默认 480p；每镜景别、机位、镜头运动、主体与背景的比例。参数描述应可供视频模型理解，不虚构实体相机设备。
4. **活动与时间轴**：30秒产品片为9/9/12秒，45/60秒按不同机位分段，每镜不超过15秒；资料仅支持一个场景时变换已知视角，不编造适用场景。10–15秒旧数字人样片维持原时长。
5. **声音设计**：产品片由视频模型生成简短讲解、音乐、环境声，后期按实际ASR时轴添加96px粗体白字描边字幕，最多两行，不加大黑条、不替换TTS。口播须保持文案、口型和声音一致。
6. **负面约束**：不变形设备，不添零件或标识，不把大型设备缩成手持玩具；不编造清洁前后效果、医院/学校身份或未成年人面孔；不加水印、乱码字幕和多余人物。

## 生成与复核

- 逐镜保存计划、输入依据和版本。产品演示若无证据则改为静置展示，不能靠负面提示词碰运气。
- 每个场景以产品原图经现有图片供应商生成不同首帧，再生成正式480p原生音画段；不得依赖Codex订阅生图或复用同一段视频填满时长。
- 前进动作与相机方向明确，产品和经过后的区域同框；清洁变化仅发生在底盘经过之后，保留地面原有纹理。资料未支持的污物、场地或性能不加入；非清洁产品采用外观展示。
- 生成前确认分镜及预估费用。源视频用 480p；本地放大到 1080×1920 时只标注“1080p 尺寸”。它不能恢复原始不存在的细节。
- 生成失败只重做已确认失败的镜头；云端提交结果不明时先核对任务，不自动重新付费。
- 完整费用含首帧、视频和字幕识别，保存价格来源、预算汇率、实际回执与未结算预留；超额不继续提交。已付费素材的本地合成或字幕渲染失败不重复生成画面。
- 出片检查产品形状、文字、材质、人物肤色与口型、镜头连续性及声音。需要时与原生 1080p 同素材对比，决定是否升级生成档位。
