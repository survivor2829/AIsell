# 关键词获客与视频创作首轮接通说明

日期：2026-09-22。测试网关已补 APIMart 专用出站与真实列表解析，工作站临时网络出口上的免费只读调用已成功；服务器尚无长期可用的出站线路，真人样片已完成内部 12 秒样片验收，正式客户频道仍未发布。

## 入口与数据

- 关键词获客位于三个主模块下方，与产品详情图分别独立。任务、线索、会话经 `xiaoxiKeywordAcquisition` IPC 保存到 `keyword_acquisition/`，内容引擎不可用时仍可操作。
- 数字人位于内容创作 → AI生成视频。形象、产品及配置可保存为草稿；同一草稿修改不创建重复任务。场景为简洁演播室、门店陈列、产品展示台，首轮 10–15 秒。
- 根据现场反馈，数字人页面已移除视频样式、配乐控件及音乐目录查询；新建及重新保存草稿默认使用主题字幕、不加背景音乐，历史成片和已开始任务不变。场景卡片与右侧大图使用本地环境示意图（`desktop/public/digital-human-scenes/`），选择即可查看，不上传素材。真实人物与产品合成仍由“生成人物预览”发起，服务未连接和生成接口未接通分别说明原因；静态示意图不是生成验收结果。小件可拿取，大型产品在地面展示，人物站旁讲解或操作。
- 配音选项目前为 Seedance 原生声音风格，不是既有克隆音色。生成的实际声音会由内容引擎转写核对确认文案；口型、人物、产品及动作必须看真实样片验收。
- 两类视频共用 `topic_fixed`／`key_points` 包装；封面详情按成片编号精确读取，旧作品不依赖最近列表页范围。修改标题复用已保存底图；重新生成封面才可能调用供应商。
- 成片中心保存视频；作品的封面面板可单独保存图片。批次导出仍为视频文件，多平台自动发布本轮未接通。

## 外部接口

沿用统一网关和现有 APIMart 密钥配置，本轮不新增 renderer 密钥输入或源码凭据。

| 入口（统一网关前缀下） | 用途 |
|---|---|
| `POST /apimart/uploads/images` | 上传形象、产品图（既有接口） |
| `POST /apimart/images/generations` | 场景预览及封面底图（既有接口） |
| `GET /apimart/tasks/:id` | 查询已提交任务（既有接口） |
| `POST /apimart/videos/generations` | 新增 Seedance 2.5 视频任务 |
| `GET/POST /apimart/seedance2/private-avatar/assets` | 新增人物素材登记与审核结果读取；按授权隔离素材名称 |
| `GET /operations/:id` | 请求中断后查询已提交操作回执；不自动重复提交 |

测试网关已部署新增接口、专用出站和任务素材组定向查询代码，当前运行标识 `a61354d55ba81c5`。实际桌面已通过网关会话及能力检查；临时网络出口上的免费列表 GET 及主体过滤已通过，但长期出站未配置，不能仅凭能力标记认定人物审核和视频生成可用。接口适配依据 [Seedance 2.5 官方文档](https://docs.apimart.ai/en/api-reference/videos/seedance-2-5/generation)，部署证据及剩余问题见[部署记录](reports/2026-09-22-digital-human-gateway.md)。

数字人基础视频经主进程内部 `import_base_video` 进入内容引擎，复用 `source_id` 恢复本地包装；最终公开 `generated_video_id`。客户页面不能提交任意本地视频路径。封面失败单独留在作品内，已经生成的视频仍可导出。

## 分段验收

1. 本地：新建关键词任务，保存联系人数上限；新建、修改数字人草稿；退出再开，确认记录和图片仍在。供应商未就绪时生成按钮应阻断，草稿可保存。
2. 抖音：用户指定测试账号与接收账号后，先登录、确认账号身份，再用一个关键词观察实际搜索／评论。检查来源链接、评论原文、用户标识和意向信号。当前首轮意向筛选为明确的询价、购买、联系表达规则。
3. 私信：先核实当前站点私信结构、会话身份和回执，再在指定范围发送一次；分别确认发送端状态、接收端实际收到、回信被读取及 AI 回复。现阶段页面不满足这些证据时显示待接通；不把点击发送当成功。未知结果保留且不自动补发，重启回人工状态。
4. 数字人：部署／权限／付费调用范围确认后，用一组授权素材检查预览，再确认生成 10–15 秒样片。逐项核对人物、产品、手部、声音、口型、文案；语音识别未通过时保留基础视频和具体原因。
5. 成片：检查顶部标题、分段要点、黄白重点字与声音同步，避免挡脸和遮产品；生成封面后改标题，核对供应商没有新增生图请求；分别保存视频与封面。模拟封面失败后视频仍可查看导出。
