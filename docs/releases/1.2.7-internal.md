# 1.2.7 内部更新

产品效果视频新建任务改用阿里Wan3、默认480P，由产品原图直接生成各场景画面，不额外购买场景首帧。清洁设备按资料安排真实经过后才产生结果、结果持续保持的画面；不适用的场景不因选择而变成支持。旧任务保留原模型与回执。

线索视频混剪使用统一下载入口选择保存位置，显示成功／失败反馈；单条作品左侧视频、右侧文案，窄窗口自适应。后续新混剪使用原画面封面，取消额外课程色块与封面包装，保留正常字幕及所有历史视频。

本机用户已确认入口能跑通；实际30秒Wan3任务三个镜头完成，成片视频与音轨全片解码通过。其他电脑、不同产品与场景仍待验收；480P最终普通放大不等于原生1080P或AI超分，费用以账单为准。

本次仅内部test频道，不开放正式客户频道，不包含新的付费测试或真实微信发送。CI、候选及安装升级结果以本次发布验收记录为准。
