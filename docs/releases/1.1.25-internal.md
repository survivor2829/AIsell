# 1.1.25 内测更新

- 精准触达可以重新组合 OCR 拆开的“微信号”标签和微信号片段，并兼容大小写、全半角和空格差异，减少不同电脑上明明搜索到联系人却被判定身份无法确认的问题。
- 搜索身份暂时无法确认时，先对当前联系人自动恢复两次，仍失败才只跳过这一位；发送前检测到人工输入占用时，等待 15 秒后自动继续当前联系人，不再暂停整项任务。

本版已通过 OCR 拆词及错号、网络回显反例、身份识别有界恢复、人工输入占用恢复、调度续跑、未知发送结果不重发等 headless 故障注入，以及精准触达全链路 dry run 和测试界面构建。

格式识别可以宽松，但重组后的微信号仍须与目标一致且结果唯一；账号、授权、会话身份变化及发送结果不明仍会阻断，系统不会自动补发。真实微信、原故障电脑和不同微信版本仍需异机验收。本版仅发布到内部 `test` 频道。
