# 1.1.24 内测更新

- 精准触达在搜索结果身份无法确认、且明确没有点击或发送时，会隔离跳过当前联系人并继续下一位，不再因一条搜索识别失败暂停整项任务。
- 一次启动已授权并冻结整份联系人清单后，任务跨过每 50 人的文案准备边界会自动进入下一批，不再要求重复点击继续。

两台 1.1.23 故障电脑均在点击发送前返回 `search_result_identity_unverified`，本版按故障作用域修正为单联系人隔离。搜索失败隔离、51 人连续运行、重启续跑、未知发送结果不重发、剪贴板与窗口故障等 headless 回归，以及完整源码自检和测试界面构建均已通过。

账号、授权或目标窗口身份失真仍会阻断；已经点击或发送结果不明时不会自动补发。真实微信、两台原故障电脑及不同微信版本仍需异机验收。本版仅发布到内部 `test` 频道。
