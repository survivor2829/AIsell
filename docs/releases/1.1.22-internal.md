# 1.1.22 内测更新

- 精准触达不再假设搜索结果控件名称等于微信号；联系人名称与微信号不同时，也会按唯一的本地联系人结果继续。
- 微信内部控件暂时不可读时，补充搜索结果区域视觉确认；无法唯一确认会暂停，不会点击“搜一搜”或连续跳过后续联系人。
- 发送点击后首次无法确认结果时，仅针对输入框瞬时读取失败重新核对同一账号、窗口和会话，再做一次只读确认；不会再次点击发送。

本版已通过空控件树、名称与微信号不同、仅有“搜一搜”、多候选、识别不可用、首次发送确认失败后恢复及持续失败仍暂停等无真实发送故障注入，以及精准触达全链路 dry run、完整源码自检和测试界面构建。

真实微信异机任务仍待验收。只有明确没有本地联系人时才跳过；身份、会话或两次发送结果确认仍不明时不会自动补发。本版仅上传内部 `test` 频道。
