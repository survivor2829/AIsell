# 1.1.23 内测更新

- 精准触达在微信内部控件不可读时，只接受本地联系人区域内带完整“微信号”标签、且与搜索值完全一致的视觉结果。搜索框回显、“搜一搜”区域文字、名称相同或多个候选都不会触发点击。
- 历史任务因发送结果无法确认而暂停时，可在任务页核对微信后选择“已发送”“未发送”或“跳过”。处理动作本身不会发送，只有再次点击启动后才继续剩余任务。

已通过截图形态、网络回显、越界/缺失边界、多候选、旧 1.1.20 单文字状态、三种人工决议、写盘中断对账及可信点击错配等 headless 故障注入；精准触达主自检、消息顺序、任务编排、完整源码自检和测试界面构建均通过。增量候选仍须完成同提交校验，具体结果以最终发布记录为准。

真实微信、原故障电脑及不同微信版本的异机验收尚未完成。发送结果不明时必须先人工核对，系统不会自动补发。本版仅计划发布到内部 `test` 频道。
