## 为什么返工（错在任务卡，不在实现）

T1 卡的规则是"人名段 1–3 字，首字是姓就取首字"，Codex 严格照做了。但这条规则在"两字地名或品牌 + 姓 + 职务"这种极常见的备注上会**把原来叫对的改成叫错**。审查实测有 36 条回归，例如：

- 苏州陈总 → 苏总
- 万科李总 → 万总
- 华为李总 → 华总
- 平安李经理 → 平经理
- 高三王老师 → 高老师

原因是："刘国强"和"苏州陈"这两种结构，只靠一张大姓氏表分不开。另外还有两条叫错路径：
- 备注被拒绝后，代码会转去解析客户自己起的**昵称**，例如"房产经理"被叫成"房经理"；
- 备注里带关系词时，会把助理、司机当成老板本人，例如"王总-司机"。

原则不变：**宁可只说"早上好"，也不能叫错。**

## 新规则（Claude 已用约 130 条样例做原型验证：叫错 0 条）

1. **只用备注**：备注（remark）非空时只解析备注，不再回退到昵称。只有备注为空时才看昵称（nickname）。
2. **关系词一票否决**：文本里只要出现以下任一词，直接返回 generic：
   助理、秘书、司机、老公、老婆、爱人、太太、夫人、家属、儿子、女儿、介绍、推荐、朋友、同事、亲戚、的
3. **职务**：按 `总经理|总监|总|经理|主任|老师|老板` 的顺序匹配，"总经理"输出为"总"（王总经理 → 王总）。职务前必须是文本开头或分隔符（空格、中英文逗号和顿号、分号、冒号、下划线、各种横线、`·`、`/`、`|`）；职务后必须是结尾、分隔符或 6 位以上数字。
4. **边界词**：人名段从最后一个边界词之后开始。边界词为：
   公司、集团、科技、商贸、实业、中心、工作室、门店、店铺、工厂、部门、团队、区域、部、省、市、县、区
5. **两张姓氏表**：
   - `SURNAMES` = 现有 `COMMON_SURNAMES` ∪ `TOP_SURNAMES`（补上现表缺的 曾、肖、付、闫、覃）；
   - `TOP_SURNAMES` = 常见前 100 姓："王李张刘陈杨黄赵吴周徐孙马朱胡郭何高林罗郑梁谢宋唐许韩冯邓曹彭曾肖田董袁潘于蒋蔡余杜叶程苏魏吕丁任沈姚卢姜崔钟谭陆汪范金石廖贾夏韦付方白邹孟熊秦邱江尹薛闫段雷侯龙史陶黎贺顾毛郝龚邵万钱严覃武戴莫孔向汤"。
6. **按人名段长度判断**（复姓优先：以复姓开头、总长 ≤4 时取复姓）：
   - **1 字**：在 `SURNAMES` 里就取这个字（王总）。
   - **2 字**：
     - 第 1 字是"小、老、阿"之一，且第 2 字在 `SURNAMES` 里：取第 2 字（小王总 → 王总）。
     - 否则，第 1 字在 `TOP_SURNAMES`、第 2 字不在 `TOP_SURNAMES`、且整个人名段不在两字停用词表里：取第 1 字（张伟 → 张）。
     - 其余返回 generic（李白：白也是大姓，读法不唯一）。
   - **3 字**：
     - 第 1 字在 `TOP_SURNAMES`、第 3 字不在 `TOP_SURNAMES`：按全名读，取第 1 字（刘国强 → 刘）。
     - 第 1 字**不在** `SURNAMES`、第 3 字在 `TOP_SURNAMES`：按"前缀 + 姓"读，取第 3 字（上海张 → 张）。
     - 其余返回 generic。包括：苏州陈、万科李、华为李、常玉林、居委会、包子铺。
   - **4 字及以上**（非复姓）：generic。
7. **两字停用词表**（岗位或行业词，首字恰好是大姓）：
   高级、高中、高一、高二、高三、高管、高工、高端、金牌、金店、金融、白金、黄金、石油、石材、林业、龙头、韩语、马上、周末、江湖、钱包、方案、程序、田园、何时、汤锅、孔雀
