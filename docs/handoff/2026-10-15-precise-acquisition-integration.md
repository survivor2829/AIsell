2026-10-15，依据已确认 SPEC v0.2 实施；当前为工作区本地实现，未提交、部署或发布。沿用已有 dirty 分支，保留启动优化、GEO 和地图采集的既有改动。

## 已实现

- 精准获客内提供推荐商机、待补联系方式、地图潜客、我的跟进、历史与待核实。服务城市、区县、设备及销售/租赁/维修/耗材设置保存到主进程。
- 支持原文粘贴和 TXT/MD/HTML/JSON/PDF 文件导入、逐项事实核对、原文片段回看。模型整理需独立价格与预算批准；摘要只发现页面，不能作为事实依据。扫描 PDF 或缺解析器保留“未完整解析”。
- 采购、保洁物业中标、厂房仓库交付分别判断；地区按项目地点，设备和四类业务分别匹配。过期、成交、取消、日期未知、关键事实不足进入待核实/历史；采购负责人未知明确标注。地图名单不自动成为需求证据。
- 每项目一张卡，同项目更新保留证据，终止采购不会被旧消息重新激活。多项目共用企业电话、收藏和跟进。联系人身份必须有片段依据；代理电话不当买方电话。成功复制后记录事件，不标为已联系或确认需求。
- 从旧地图记录按原 ID 建立统一企业关联，迁移可重复执行，不回写/删除旧地图文件。人工确认同名主体后才关联项目，名称相似或相同电话不能自动合并。
- 主进程协调搜索、读取、模型与地图补充，保存部分结果及断点。地图同一队列暂停后恢复原任务，不另建替代搜索；登录失效及人工验证沿用地图适配器，不清账号。
- 新网关能力与素材搜索/抖音状态隔离。公开原文主机白名单、DNS 公网检查、固定已核验 IP 连接、重定向再校验；不传 Cookie。PDF 子进程有时限。诊断只存 ID、阶段、计数和错误代码，不存手机号/正文/凭据。

## 默认边界与启用条件

只有用户点击才检索。单任务最多 10 候选、12 搜索、20 读取、10 地图补充、10 模型调用，软时限 5 分钟。查看缓存、收藏、复制和跟进不触发外部调用。专业招采/工程/联系人适配未接入，不能执行。

网关未部署或来源未启用时显示“尚未接通”，不伪装为零结果。服务端独立开关：`XIAOXI_PRECISE_SEARCH_ENABLED`、`XIAOXI_PRECISE_SEARCH_BUDGET_MICROS`、`XIAOXI_PRECISE_SEARCH_COST_MICROS`、`XIAOXI_PRECISE_SEARCH_DAILY_LIMIT`；已有服务端搜索 Key 仍不足以启用请求。公开正文需要 `XIAOXI_PRECISE_PUBLIC_READ_ENABLED=1` 和 `XIAOXI_PRECISE_SOURCE_HOSTS` 精确主机白名单。可选文本 PDF 依赖见 `server/provider-gateway/requirements-precise.txt`；未安装时明确返回不可完整解析，不启用收费 OCR。

本地 AI 批准文件位于运行数据 `precise-acquisition/billing/budget-approval.json`，需要 `approved=true`、`approvedAt`、`maxCalls`、正整数 `costPerCallCeilingMicros` 与 `totalBudgetMicros`，以及 `pricing` 的真实模型名称、`currency=CNY`、`verifiedAt`、`inputMicrosPerMillion`、`outputMicrosPerMillion`。一元为一百万 micros。必须先核实供应商价格和用户预算，不能从测试样例复制批准值。本次未创建任何真实批准。

模型按输入上界及输出上限预留金额；搜索使用独立请求账本。已完成同查询结果可复用，未知结果保留预留并阻止重复购买，换任务 ID 不能绕过。费用记录是保守预留与用量记录，不冒充供应商最终账单。
