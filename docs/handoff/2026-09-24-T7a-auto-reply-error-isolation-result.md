# T7a 结果：自动回复错误隔离与恢复

- 分支：`codex/auto-reply-workflow-resilience`；基线：`08be3af`。
- 工作流接待名单逐人核对：资料变化或会话名不唯一的联系人只剔除本人；唯一性仍按完整通讯录判断，包括已停用联系人。筛选结果只让合格者进入别名、账号和运行中绑定。全员不合格时返回 `workflow_recipients_none_eligible`。
- 触达任务自动加入名单时复用同一筛选，记录剔除总数与重名人数；手动选择仍在任一联系人不合格时整体拒绝并提示具体联系人。
- AI 网络错误、超时、限流以及返回聊天失败进入 30 秒、2 分钟、5 分钟（之后保持 5 分钟）退避。AI 失败先把候选重新入队；队列不可用则暂停。退避到期重做启动检查，重放仍经过实时消息验证、回复护栏和发送前检查。配置、响应、运行状态与结果未知等其他错误继续暂停。
- 工作流 `start()` 通知自动回复重新做启动检查，并清空本轮退避与日志去重状态；不清已处理消息、回复护栏和结果未知记录。`runWorkflowStep` 的提前返回写结构化原因码诊断；调度器按 `reasonCode` 记录 `reply.result` 或 `reply.backoff`，只传原因码、计数和耗时，不传联系人或错误原文。界面显示退避提示、当前剔除人数和最近自动加入时的重名排除人数。
