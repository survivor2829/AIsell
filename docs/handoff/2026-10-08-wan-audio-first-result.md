## 用户可见变化

- 产品效果视频保留产品图片、产品名称、卖点与参数、使用场景、地面材质。取消费用上限、时长选择和补充表达输入，默认制作30秒；场景可选小区外围等，最多三个，不选则按资料安排。
- 数字人取消费用输入，保留形象、产品、口播、场景及声音设置。新版支持15/30/45秒，旧草稿继续使用原有10–15秒规则。
- 不填写费用不会阻挡新版任务。后台按完整有效报价确定并冻结制作额度；已有任务的明确额度继续保留，开始后不自动扩大额度。
- 保留现有入口、人物与页面布局；移除废弃费用表单的样式。

## 生成链路

- 新产品任务：全部场景首帧 → 文件及方案锁定 → 同一声线讲解 → 原讲解字幕时间 → 阿里官方 Wan 720p 无声镜头 → 完整声音轨合成 → 1080×1920普通放大与大字字幕。
- 新数字人：完整稿分段 → 阿里 TTS → 测量真实讲话时长、停顿与结尾覆盖 → 字词及字幕时间预检查 → 人物预览 → 同一音轨驱动 Wan → 原完整音轨包装。字数只作写稿提示，不代替实际声音检查。
- 可用授权音乐整片连续铺底；选曲、读取或混音失败保留完整讲解，不重新购买视频或配音。没有授权音乐时明确显示无配乐。
- 付费操作在请求前记录回执与预留；结果不明只查询原请求。生成失败不会自动重复购买。旧任务仍走创建时的供应商与版本。
- 网关复用原百炼路由，补齐异步/OSS请求头及上传查询参数；内容引擎增加内部选曲命令并接受冻结音轨的字幕结果，避免后期重复ASR。没有新增公开接口或数据库表。
- 本地媒体处理按实际 FFmpeg 能力选择编码器，安装包使用现有 Media Foundation 路线，修复开发机存在 libx264 而安装包没有导致的合成失败。
