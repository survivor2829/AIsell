# 线索视频混剪：配音配乐全自动、去掉强制试听、精简第 2 步（任务卡）

来源：用户 2026-10-23 反馈。在另一台电脑安装后做混剪，确认文案与画面后被要求"选择试听候选"、批准声音、配授权曲库，看不懂"视频样式""严格核对画面事实"，流程长、界面杂。诊断由 Claude 完成，实施交给 Codex。风险：中高（`sidecars/content-engine/**` 付费链路相关、`src/renderer/Batch*`）。分支：从最新 `main`（当前 `32514af`）拉 `codex/mix-auto-voice-music`。

## 用户要求（原意）

1. 配音、配乐**都不用试听**，系统自动匹配，客户不需要做选择也能直接出片。
2. 不要"严格核对画面事实"；"视频样式"客户看不懂，不要让客户选。
3. 第 2 步（确认文案与画面）之后不要再出现一大堆设置，点确认就开始制作。
4. 配乐要有：找免费、可商用、适合混剪的曲子（轻快、干净，不要怪异风格）预装进软件。

## 根因（已核对源码）

- **新电脑上没有任何"已批准"声音，制作被硬性拦住。**
  - 内置音色目录 `content_engine/assets/auto-mix-voice-personas.v1.json` 写入数据库时一律 `approved_at = None`（`creative_domain.py:530-533` 注释："Catalog configuration … cannot stand in for the user's preview-and-approve action"）。
  - 批准必须先有试听文件（`approve_auto_mix_voice_persona`，`creative_domain.py:1354-1377`，否则报 `auto_mix_voice_preview_required`）；火山试听可能计费，界面因此加了付费确认（`BatchSoundSettings.tsx:71-90`）。
  - 混剪三处硬要求已批准声音：`narrated_batch.py:898-908`、`:1262`，`narrated_production.py:274-277`。
  - 界面：声音下拉默认项是"试听后选择声音"（`BatchSoundSettings.tsx:109`）；没有声音时"声音与配乐"自动展开（`BatchCreativePage.tsx:609`），"确认文案，开始制作"按钮要求 `settings.voice_persona_id`（`:615`），并提示"请在上方选定已批准的声音"（`:617`）。
  - 后端本来支持"批次没选声音就用已批准声音"（`_require_approved_voice` 注释），只是新机器上一个都没有。
- **配乐：** 默认已是"自动配乐（授权曲库）"，但曲库只能由用户导入（`import_music_catalog_track`，需授权证据），新电脑为空，所以只有配音。
- **视频样式 / 严格核对：** `VideoTemplatePicker`（`VideoPresentation.tsx:5-12`，两种字幕版式"主题常驻/分段要点"）和"严格核对画面事实"复选框（`BatchCreativePage.tsx:611-612`，默认已关）都直接摆在第 2 步主界面。

### 同一根因还影响另外两个视频功能（2026-10-23 追加审查）

- **数字人视频**：官方声音要求 `available`（`digital-human-service.cjs:58`、`:303-305`），而 `availability` 只有"已批准且试听完成"才算可用（`creative_domain.py:4458`）。新电脑会报"所选声音尚未完成试听或账号不可用，请先试听该声音"。
- **产品效果视频**：开始前的能力检查（`product-video-service.cjs:143-155`）不检查声音，显示"可以生成"；跑到 `preparing_audio` 才因 `prepare_video_narration` 找不到已批准声音而失败（`creative_domain.py:5755-5759`），提示"请先在创作工作台确认一个可用的配音声音"，客户不知道"创作工作台"在哪。
- 所以第 1 条修改要让三个功能（混剪、数字人、产品效果视频）在新电脑上都直接可用；产品效果视频的能力检查要把"有可用默认声音"算进去，不满足就在开始前提示，不能跑到一半才失败。

## 修改要求

1. **官方音色免试听可用（混剪、数字人、产品效果视频共用）**
   - 内置目录里 `provider = volcengine`、带固定 `providerVoiceId` 的官方音色（如"小何 2.0"），视为产品方已选定，首次写入或升级时自动标记为可用（approved），**不需要试听文件**。需要"设计"生成的百炼音色保持原规则。
   - 未选声音的批次自动用默认音色：优先 `digitalHumanDefault`，其次 `autoSelectPriority` 最高的火山官方音色。三处后端校验在"未指定声音"时都要能找到这个默认音色。
   - 保留：客户主动选过的声音继续生效；已有"批准失效/音色不可用"的恢复逻辑不变；付费试听仍需确认，但只在客户主动点试听时出现。
2. **预装免费配乐**
   - 照 `BUILTIN_VOICE_CATALOG` 的做法新增内置曲库目录（曲目文件 + JSON 清单 + 每首的授权证据文件），首次启动或升级时写入曲库，走现有 `licenseSummary` 校验，可被"自动配乐"选中。
   - 选曲标准：纯音乐无人声；轻快/明亮/轻电子/轻企业风，约 95–128 BPM；单曲 1–3 分钟或可循环；不要悬疑、恐怖、搞怪、强烈 EDM、国风戏曲、儿歌等风格。先备 15–20 首，覆盖"轻快、温暖、科技感、稳重"四类。
   - **授权硬性要求**：只收 CC0（公有领域）或许可证**明文允许随软件再分发**的曲子。Pixabay、Mixkit 等"免费可商用"许可禁止原样单独分发（standalone），打包进收费软件有风险，不能用，除非书面确认允许。每首保存来源网址、作者、许可证全文或截图、下载日期，放进授权证据。找不到足够合规曲目时停下来报告给用户，不要凑数。
   - 候选来源（Codex 逐首核实许可）：Free Music Archive / Openverse 按 CC0 筛选；或由用户购买带"应用内分发"授权的商用曲包。
   - 自动选曲在曲库有可用曲目时必须配上音乐；只有在客户明确选"不加配乐"时才没有。
3. **精简第 2 步界面（结构不变，只收起）**
   - 主界面只保留：选定文案方案、做几条、"确认文案，开始制作"按钮，以及一行摘要："声音：自动（小何 2.0）· 配乐：自动 · 字幕：主题常驻"。
   - "声音与配乐""品牌""视频样式"全部收进一个默认**收起**的"更多设置"，不再因为没有声音而自动展开。"视频样式"改名"字幕样式"，默认"主题常驻"。
   - 去掉主界面上的"严格核对画面事实"复选框，保持默认关闭；如果要保留功能，只放在"更多设置"最底部。
   - 声音下拉默认项改为"自动选择（推荐）"；"选择试听候选"改为"更换声音"并放进更多设置；去掉"请在上方选定已批准的声音"提示。
   - 确认按钮不再要求 `voice_persona_id`。
4. 第 1 步右栏（`BatchCreativePage.tsx:589` 的"AI 解说声音"）同样默认"自动选择"，不强制。

## 禁止

- 不发布、不在真实账号上批量付费生成；验证用最少条数，且先告知用户预计费用。
- 不放进任何来源或授权不清的音乐；不删除或改写客户已导入的曲目和已批准的声音。
- 不改文案生成、镜头编排、成片导出等其他环节。
