# 数字人口播：模板、独立 AI 封面与自然配音

## 基线与范围

- 工作树 `1ac9`，分支 `codex/reference-person-avatar`，基线 `31d488c`／1.1.93。接续未提交的人物资产与声音链路，未覆盖其他工作树；未提交、推送、打包、发布或部署服务器。
- 用户本轮授权：一张 AI 封面最多预留 ¥1.69，一份自然交谈配音及字幕核对最多预留 ¥2.00，合计 ¥3.69；不购买音色、不重新生成数字人、不自动重试付费请求。
- 实际新增云端请求：封面生成一次、TTS 一次、ASR 一次；人物生成和音色建立均为零。预留不是实扣，尚未核对账户账单；供应商封面回执 cost 字段没有明确币种，不据此换算人民币。

## 实现

- 三套版本化模板：层次分句、重点弹字、简洁口播。统一主题标题、大小字、颜色、位置、分句与动效；真实动态卡片复用渲染组件。只强调确认的短语，移除单字关键词猜测；没有逐词时间时不假造逐词跟读。
- 长句按真实字幕边界分页，保护强调短语和标点，平衡换行，避免单字孤行；旧样式 ID 和任务兼容。
- 换模板走本地重新包装，复用人物原片、配音、字幕和配乐。确认页区分本地免费包装、配音与字幕费用、后续人物费用。
- 独立整张 AI 封面：确认标题、口播文案、本地人物清晰帧、三种设计风格；请求 3:4，输出 1080×1440，不叠旧标题、不插入视频。支持报价、确认、原任务查询、历史恢复、放大与独立下载。
- 自然交谈指令和正文分开存储，语速／音调仍为 1，参数纳入报价快照与复用判断。正文不改写；先试听，人物生成另行确认。
- 发布源码复制与 Remotion 运行时摘要包含新增模板配置和组件；本轮只构建界面及轻量渲染 bundle，没有完整打包。

## 实际发现并修复的根因

1. 人物封面参考帧路径达到 273 字符，Windows 严格路径解析在网络调用前失败。离线网络陷阱复现证明调用数为零。改为浅层 cover-references 缓存，并在费用准入前实际打开、读取参考帧。仅对隔离验收数据库中这一条无供应商 ID 的误记提交回执做有证据的失败纠正，保留原回执；之后才发出唯一一次实际生成请求。
2. 已生成图片的 CDN 在本机代理 FakeIP DNS 下解析为基准测试地址，原安全校验阻止下载。仅对明确 FakeIP 情况使用 HTTPS DNS 解析，要求全部公开 IPv4，下载连接固定到已校验 IP，TLS 仍验证原域名；重定向逐次校验，私网继续拒绝。多个公开地址按总超时依次回退，不修改系统代理／DNS。通过“查询原封面”恢复同一供应商任务，未重新购买。

证据保存在 `desktop/.build/narration-v1/local-cover-path-reconciliation.json` 及同目录下载／恢复记录；签名 URL 与运行资料不进入源码或发布包。
