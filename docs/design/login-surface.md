# 登录页局部设计约定

## 页面模式与范围

- 模式：Operate。核心任务是输入或复用授权码，明确点击「登录」进入工作区。
- 本文只约束登录页；不将星空、深色表单或配色扩展为全项目设计规范。
- 实现依据：`desktop/src/renderer/LoginScreen.tsx`、`LoginScreen.css`、`LoginStarfield.tsx`、`LoginStarfield.css` 与 `App.tsx`。

## 视觉与动效

- 全屏由柔和靛蓝经浅紫过渡至玫粉，使用低频、连续的实时云层，保持大块留白；用户已明确拒绝密集星系照片和星尘纹理。
- 中央表单最大宽度 440px，圆角 16px；以高不透明度深蓝到暗紫渐变和阴影保证阅读稳定，不随鼠标漂移。
- 主文字 `#f5f0ff`，辅助文字 `#c3bbd5`；主按钮由浅蓝 `#bdd6ff` 渐变至粉红 `#f2bad6`，深色按钮文字 `#241735`。
- 云层以 WebGL 实时绘制，不使用背景图片；鼠标附近产生局部形变、柔和光晕与宽涟漪，最多保留四段衰减轨迹及十六颗极淡细星。画布最高 1280×900、约 30fps，失去 WebGL 时回退至可随鼠标响应的 CSS 渐变。
- 星空是装饰层，不拦截点击；触屏不触发指针响应。减少动态效果设置下静态绘制，页面隐藏时暂停动画。
- 窄屏缩减留白，低高度压缩纵向间距；内容不足以容纳时允许滚动，保持表单可操作。

## 交互约定

- 保留授权码机制；每次启动或重载均停留登录页，即使已有有效授权也须点击「登录」。
- 沿用主进程授权接口及本机安全保存机制；已存授权显示标识，可切换「更换授权码」或「使用已存授权」。
- 新输入默认隐藏，可切换显示；验证中禁用重复提交，失败在表单内提示，失效授权转为重新输入。
- 输入具有关联标签、错误提示和清晰焦点环；错误使用 `role="alert"`，读取状态使用 `role="status"`。

## 验证边界

- `npm.cmd run build:test` 已通过；本轮验证使用本机 Electron。用户已确认沿用当前柔和互动云雾版本并提交收尾。
- `outputs/login-review/comfort-desktop.png`、`comfort-pointer-left.png`、`comfort-pointer-right.png`、`comfort-compact.png` 为隔离授权 fixture 的真实 Electron 截图；`comfort-results.json` 确认 WebGL、无背景图片、左右鼠标位置响应、紧凑窗口无溢出及减少动态效果时静态。截图后仅将右下角文字进一步加深至 `#21162a`，增加对比度余量。
- `outputs/login-review/results.json` 记录隔离 fixture 的 Electron 验证：动态变化、空值提示、紧凑布局、已存授权仍需登录、点击进入及重载返回登录。
- fixture 验证不代表真实授权服务、安装包或真实微信业务验收；真实授权码激活与续期仍需在对应环境复验。
