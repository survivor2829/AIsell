# 客户可见的三位负责人

玺联惠保留为品牌名。客户界面只展示三位数字人负责人；功能页用原本的功能名称、图标和操作内容，不再展示子角色姓名、立绘或对话。人物名称与业务路由、任务数据分开，界面简化不改变已有任务。

| 负责人 | 主模块 | 功能入口 |
| --- | --- | --- |
| 周联客 | 精准获客 | 关键词获客、产品详情图 |
| 叶映客 | 短视频获客 | 创作工作台、产品效果视频、成片中心、数字人视频 |
| 许玺达 | 微信拓客 | 精准触达、自动回复、朋友圈运营；今日计划、联系人同步和 AI 专家保留在次级入口 |

素材仓库是独立功能入口，不归属某位子角色。视频导演的规划规则仍在后台运行，生成页只展示方案、进度和结果。

此前提供或生成的子角色图片保留为设计素材，不在当前客户界面展示；不需要为功能页继续补人物图。
