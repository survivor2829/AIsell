## 后续复用方法

复用的是“产品实际作业产生可见结果，并在后续画面持续保持”的逻辑，不是把所有场景写成绿色地坪。

1. 根据新产品参考图描述外观、机头方向、实际工作部件及能力，不继承BG1名称、颜色、轮子或组件描述。没有依据的能力和性能不写入。
2. 按用户提供的场景确定地面材质、颜色和污染类型。清洁后的地面应恢复同一材质的本色；不把石材、瓷砖或其他地坪改成绿色环氧地坪，不把真实磨损当作能清除的灰尘。
3. 开始交代污染和产品位置，中段展示实际作业，结尾留出空间展示结果。优先使用固定机位、单场景、单一连续动作，同时看清作业前、作业位置及作业后区域。
4. 只有工作部件实际经过后才出现效果；清扫设备的经过区域不能残留灰尘、砂砾或纸屑。根据真实作业宽度保留未经过的污染区域作参照，不能让整块地面提前变干净。
5. 效果一旦出现，应在后续画面持续保持，不能返灰或恢复污物；对10秒样片尤其检查中后段，包括此前容易出问题的第6、7秒。
6. 先保证结果可信和产品不变形。刷盘转动可描述为真实动作，但不为强调细节牺牲清洁结果，也不增加无关特写、标题包装或未经证实的效率、杀菌承诺。
7. 多场景先分别组织各场景的动作与结果，再考虑剪辑；不同产品分别使用对应参考图，不能把单张BG1直出成功当成多产品、多场景都已验证。非清洁产品只复用“动作—结果—持续”的结构，另定真实的结果标准。

当前480P、10秒是已选样片的基准，并不是所有产品、场景和时长的固定限制。同样提示词和参数也不保证重现完全相同的视频。后续实际生成须另有付费授权；未知订单先查询，不自动重提。
