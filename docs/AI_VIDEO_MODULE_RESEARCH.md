# AI 生成视频模块（Seedance 2.5）落地调研报告

> 调研日期：2026-09-02。能力事实以火山引擎控制台与官方文档为准；本文结论用于模块设计，不代表已完成实机验收（验收口径仍以 `PROJECT_STATUS.md` 为准）。

---

## 0. 结论摘要

1. **Seedance 2.5 已可接入**：2026-08-07 起火山引擎方舟（ModelArk）API 全量开放，异步任务制（创建任务 → 轮询/回调取结果），国内直连成本约为第三方转发平台的一半。
2. **单次原生直出 4–30 秒**，不是拼接；60 秒 / 2 分钟通过「尾帧续接链」实现，官方 API 提供 `return_last_frame` 参数专门支持该玩法。
3. **"通用提示词"的正确答案不是让用户写提示词**，而是建一条「产品信息表单 → DeepSeek 生成营销分镜 JSON → 模板引擎渲染成 Seedance 时间戳提示词」的管线。用户只填卖点，提示词由系统产出。本项目已有 DeepSeek 接入，可直接复用。
4. **AI 数字人口播**可用 Seedance 2.5「形象参考图 + 音频参考」原生音画同步实现（同一套 Key 和任务管线）；专业数字人平台 API（百度曦灵等）作为备选。
5. **项目地基已具备**：`bailian-api-key.cjs` 的密钥管理模式、`content-engine` sidecar 的媒体处理通道、`remotion-packaging` 的程序化合成能力，分别对应新模块的「密钥层 / 合成层 / 模板层」，新增成本主要在编排层。

## 1. Seedance 2.5 能力核实

### 1.1 接入方式

- **平台**：火山引擎 → 方舟（ModelArk）→ 开通 Seedance 2.5 → 创建 API Key。
- **调用模型**：`POST https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks`，异步返回 `task_id`；再轮询 `GET /api/v3/contents/generations/tasks/{id}` 或配置 `callback_url` 接收状态（queued / running / succeeded / failed / expired）。
- **Model ID**：形如 `doubao-seedance-2-5-*`（国际版 BytePlus 为 `dreamina-seedance-2-5-260628`）。**以控制台当前可用 ID 为准，代码中做成配置项，不硬编码。**
- **SDK**：官方 `volcengine-python-sdk` / Node 可直接 HTTPS 调用，无强依赖。

### 1.2 关键参数与上限（Seedance 2.5）

| 维度 | 能力 | 备注 |
|---|---|---|
| 单次时长 | **4–30 秒**（-1 自动适配），97–721 帧 | 30 秒为单次直出，非拼接 |
| 分辨率 | 480p / 720p（API 当前仅发布这两档） | 1080p/4K 未发布，不要做预算依据 |
| 帧率 | 24–30 FPS | |
| 宽高比 | 21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16 / auto | 短视频带货主用 **9:16** |
| 参考素材 | **最多 50 个**：30 图 + 10 视频 + 10 音频 | 图锁形象/产品，视频锁运镜/动作，音频锁节奏/音色 |
| 音频 | `generate_audio` 原生音画同步 | 环境音、动作音效与画面空间距离匹配 |
| 时间戳提示词 | 支持 `[0s]…[3s]…` 秒级分镜指令 | 长叙事不混乱的核心手段 |
| 时间戳编辑 | 对指定片段定向增/删/改 | 局部迭代，不必整段重抽 |
| 尾帧返回 | `return_last_frame: true` | **官方为连续拼接设计**，见第 2 节 |
| 参考视频输入 | 单段 [2,30]s，最多 10 段共 ≤30s | 视频编辑任务 [4,30]s |

### 1.3 成本（火山引擎直连，刊例）

- 计费公式：`tokens ≈ (输入视频时长 + 输出时长) × 宽 × 高 × 帧率 ÷ 1024`；仅成功生成的视频计费，审核失败不扣费。
- 单价：**不含视频输入 70 元/百万 tokens；含视频输入 42 元/百万 tokens**（注意：含视频输入单价更低，但输入时长也计入 tokens）。
- 实测换算（16:9）：

| 成片 | 480p | 720p |
|---|---|---|
| 5 秒 | ≈ 3.4 元 | ≈ 7.6 元 |
| 30 秒 | ≈ 20 元 | ≈ 45 元 |
| 60 秒（2 段续接） | ≈ 40 元 | ≈ 75–90 元 |
| 120 秒（4 段续接） | ≈ 80 元 | ≈ 150–180 元 |

- **成本控制策略（重要）**：草稿一律 480p（约为 720p 的 44% 价格）确认结构，定稿后才用 720p 出片；续接段的参考帧/参考视频裁到最短必要长度（参考视频每秒都计费）。

## 2. 长视频方案：30s → 60s → 2min 怎么实现

### 2.1 先纠正一个认知：AI 漫剧 25 分钟不是"一次生成"

AI 漫剧的工业化管线是：**剧本（LLM）→ 分镜 JSON → 角色/场景资产锁定 → 逐镜生成（每镜 3–10 秒）→ 剪辑合成（FFmpeg）**。25 分钟 = 几百个短片段的组装。我们的线索型营销视频（30s–2min、6–20 个镜头节拍）是**同一管线的轻量版**，且 Seedance 2.5 把单段上限拉到 30 秒，段数比漫剧少一个量级，工程复杂度大幅下降。

### 2.2 三种续接机制对比（行业共识）

| 机制 | 原理 | 画面保持 | 镜头连续性 | 坏段代价 | 适用 |
|---|---|---|---|---|---|
| Native extend | 把成片喂回模型续写 | 误差逐段累积 | **最好**（运动矢量保留） | 坏第 3 段则 4、5 段全废 | 长镜头推拉/环绕 |
| **首尾帧链式** | 第 N 段尾帧 = 第 N+1 段首帧 | 衰减较慢，接缝像素级一致 | 较弱（镜头从静止重启） | 仅重抽该段 | **分镜明确的营销片（推荐主用）** |
| 首尾帧夹逼 | 首尾两帧都人工指定 | 最稳 | 需在静帧中暗示运镜 | 仅重抽该段，可反复迭代 | 需要精确落版的片段 |

**推荐组合**：主线用「首尾帧链式」（官方 `return_last_frame` 直接给尾帧，喂给下一段图生视频）；单段内部用 30 秒时间戳提示词承载 3–4 个节拍；需要一镜到底的局部用 extend。

### 2.3 一致性工程：状态台账（Continuity Bible）

多段生成的翻车点不是"接缝"，而是**身份/场景漂移**。行业做法是维护一份贯穿全片的结构化状态，每段生成时原样注入提示词：

```json
{
  "character": {"identity": "同一位30岁女性主播", "wardrobe": "米白色西装", "fixed": "短发、珍珠耳环"},
  "product":   {"identity": "与参考图1完全一致的精华液", "fixed": "瓶身几何、标签位置、logo 不可变"},
  "world":     {"location": "浅灰极简直播间", "light": "左上方柔光，暖色调"},
  "camera":    {"language": "腰部高度平拍，缓慢推近", "screen_direction": "人物始终在画面左三分之一"},
  "audio":     {"bed": "轻背景音乐持续，无硬切"}
}
```

八要素：**身份、位置、朝向、动作姿态、道具、环境、光照、镜头/音频**——除非剧情要求，否则逐段保持。每个续接段提示词以「直接从参考帧继续 + 重申锚点 + 只描述新动作」开头，每段只做一件事。

### 2.4 分段与交接的工程规则

1. **切分点选稳定视觉状态**（动作落定后），绝不在最难动作中间切。
2. 交接帧不一定取最后一帧：取末尾最锐利、姿态正确的一帧（尾帧常有运动模糊）。
3. 每段首秒必查：姿态跳变 / 变脸 / 光照偏移 / 镜头重置——首秒不行就重抽，不看后段。
4. 每次只改一个变量重试；宽高比、参考帧、锚点描述全程锁死。
5. 合成时先裁重复帧硬切；仅当光照/运动微差暴露时加 ≤6 帧极短叠化（长叠化会在人脸处重影）。
6. **2 分钟片的实务建议**：营销线索片 60s 已是转化上限区间，2min 仅建议「数字人口播 + B-roll 混剪」形态（口播主线 + 产品画面插切），不建议 4 段纯连续叙事——漂移与成本都翻倍。

## 3. 营销提示词工程：「通用」如何落地

### 3.1 核心答案：模板管线，而不是让用户写提示词

```
用户填表单（产品名/卖点/人群/风格/CTA/参考图）
   → DeepSeek 生成营销分镜 JSON（每拍：时长/画面/运镜/台词/字幕/音效）
   → 模板引擎渲染为 Seedance 时间戳提示词 + 参考素材角色分配
   → Seedance 生成 → 合成
```

DeepSeek 在本项目中已接入（`deepseek-api.cjs`），分镜 JSON 走与自动回复相同的「严格 JSON + 结构校验」模式，失败回退到人工确认话术的同型机制。

### 3.2 分镜 JSON 契约（模块内部标准）

```json
{
  "video_type": "product_ad",
  "total_seconds": 30,
  "aspect_ratio": "9:16",
  "style_pack": "cinematic_warm",
  "beats": [
    {"t": "0-3s",  "job": "hook",     "visual": "…", "camera": "…", "audio": "…", "subtitle": "…"},
    {"t": "3-15s", "job": "pain_demo", "visual": "…", "camera": "…", "audio": "…", "subtitle": "…"},
    {"t": "15-25s","job": "proof",     "visual": "…", "camera": "…", "audio": "…", "subtitle": "…"},
    {"t": "25-30s","job": "cta_hero",  "visual": "…", "camera": "…", "audio": "…", "subtitle": "…"}
  ],
  "constraints": ["产品几何/标签/logo 不可变", "无硬切", "结尾 hero 帧留出 CTA 文字区"]
}
```

### 3.3 营销 30 秒三段式结构库（线索转化导向）

| 结构 | 节拍分配 | 适用品类 |
|---|---|---|
| 痛点→方案→亮相 | 0–6s 可见痛点 → 6–20s 产品解决过程 → 20–26s 效果 → 26–30s 产品 hero | DTC 功效型产品 |
| 氛围开场→品牌时刻→情绪收尾 | 0–8s 氛围 → 8s 前必须出产品 → 至 24s 一个记忆点动作 → 情绪落版 | 服饰/美妆/生活方式 |
| Hook 声明→证据→CTA | 0–3s 一句人群痛点 → 2–3 个效果证据 → 直接行动号召 | SaaS/课程/服务 |

线索片的铁律：**前 3 秒必须有视觉打断点**；25s 前完成价值演示；最后一帧留干净 CTA 区（文字后期加，不让模型生成文字——AI 生成的文字/logo 不可控，这是行业共识）。

### 3.4 提示词六要素模板（三个板块共用骨架）

`主体+动作` ＋ `镜头调度` ＋ `风格光影` ＋ `场景节奏` ＋ `参考一致性声明` ＋ `负面约束`

**文生视频示例（电商精华，9:16，30s）：**

> 电影感暖调，浅灰极简直播间，柔和左上方主光。
> [0s] 精华瓶（与参考图1完全一致）在大理石台面特写，瓶身凝露，镜头微距缓慢环绕
> [4s] 一只女性的手拿起瓶子，瓶盖开启有清脆声
> [8s] 同一女性（与参考图2一致）在镜前将精华滴于手背，质地拉丝特写
> [15s] 镜头横移跟随她涂抹面部，皮肤光泽变化，表情放松
> [22s] 产品立于画面右三分之一 hero 位，人物虚化在后，留白左区供后期 CTA
> [28s] 镜头定格，仅环境音渐弱。
> 约束：瓶身几何、标签、logo 不可变；无硬切；无文字生成；全片同一暖调。

**图生视频要点**：参考图定义产品与构图，[0s] 只写第一个动作；图生视频的宽高比跟随源图，需在上游把产品图规范成 9:16。

**数字人口播要点**：形象参考图（正面、无遮挡、光照均匀）＋ 音频参考（TTS 配音）＋「人物正对镜头口播，口型与音频同步，仅自然头部微动与眨眼，肩部以上构图，背景为浅灰直播间」。口播文案每段 ≤30s，长口播拆段后用数字人主线 + 产品 B-roll 插切合成。

### 3.5 参考素材角色分配表（防素材互相污染）

| 素材 | 职责 | 明确排除 |
|---|---|---|
| 图1 | 产品外观/包装 | 镜头角度 |
| 图2 | 人物形象/服装 | 背景 |
| 视频1 | 手部动作与节奏 | 参考中的人物与场景 |
| 音频1 | 配音节奏/情绪 | 画面风格 |

## 4. AI 数字人口播：两条路线

| 路线 | 方式 | 优势 | 风险 |
|---|---|---|---|
| **A. Seedance 2.5 原生（推荐主线）** | 形象参考图 + 音频参考（TTS）→ 音画同步口播段，30s/段 | 同一 Key、同一任务管线、同一状态目录；可混剪 B-roll | 长口播需拆段；极端近景口型需实测 |
| B. 专业数字人 API | 百度曦灵「照片数字人」：照片+文本/音频→口播视频（支持透明背景） | 口型专项优化、长文本驱动（2 万字） | 第二套密钥与合规审核；风格偏"播报腔" |

TTS/声音复刻建议直接用**火山引擎语音合成**（与 Seedance 同一账号体系，一个 Key 管理面）。
合规红线（必须写进产品）：**用户上传的形象图与音色必须取得本人授权**，UI 需有明示确认勾选项；生成内容按监管要求加 AI 生成标识（`--wm` 水印参数默认开启）。

## 5. 项目落地架构（对齐 AGENTS.md 规范）

### 5.1 模块文件规划

```
desktop/src/main/
  volcengine-api-key.cjs            # 密钥管理，复刻 bailian-api-key.cjs 模式
  volcengine-api-key.self_check.cjs #   （safeStorage 加密 .bin + host 白名单 ark.cn-beijing.volces.com + 掩码）
  ai-video-script.cjs               # DeepSeek 分镜 JSON 生成（复用 deepseek-api.cjs，严格 JSON 校验）
  ai-video.cjs                      # 任务编排：创建/轮询/续接链/状态机/成本预估
  ai-video-ipc.cjs                  # IPC 层（renderer 不直连火山、不读密钥）
  ai-video*.self_check.cjs          # dry-run 自测：参数校验、模板渲染、状态机流转，不发起计费请求
desktop/src/renderer/
  AiVideoStudioPage.tsx/.css        # 三板块 Tab：文生视频 / 图生视频 / AI数字人
desktop/sidecars/
  ai-video-assembler/               # FFmpeg 合成 sidecar（拼接/字幕/BGM/叠化），
                                    # 或并入现有 content-engine sidecar 扩展 media-tools
```

### 5.2 运行状态隔离

新增 `data/ai_video/` 与 `contact_sync/`、`active_touch/` 等平级：

```
data/ai_video/
  drafts/      # 分镜 JSON 草稿（用户确认后冻结，同主动触达话术冻结机制）
  tasks/       # 每任务一目录：请求参数、task_id、轮询状态、逐段结果
  assets/      # 用户上传的形象图/产品图/音频（本地保存，不进 Git/ZIP）
  segments/    # 各段成片 + 交接尾帧
  exports/     # 最终合成成片
```

`wechat_adapter/` 不涉及本模块；本模块产物如需进朋友圈/私信发送，走既有 moments/主动触达通道验收，不自带发送能力。

### 5.3 沿用项目既有红线

- **密钥**：火山 Key 只在「API 密钥」页填写，safeStorage(DPAPI) 加密存运行目录，renderer 只见掩码；不进源码/Git/日志/ZIP。
- **授权**：self-check 只做 dry-run（不扣费）；真实生成每次需用户确认，并前置展示**成本预估**（时长×分辨率×段数）。
- **失败语义**：生成失败/审核失败不自动重试扣费；状态不明标 `unknown`，不伪装成功；单段失败仅隔离该段（对齐 fallback 哲学）。
- **发布**：密钥、素材、成片不进便携包；manifest 与实机验收同版本。

### 5.4 分阶段路线

| 阶段 | 内容 | 验收 |
|---|---|---|
| P1 | 密钥模块 + 文生/图生单段 ≤30s + 分镜脚本管线 + 成本预估 | self-check + 用户授权的 1 条 480p 真实生成 |
| P2 | 尾帧续接链（60s/120s）+ FFmpeg 合成（字幕/BGM/转场） | 60s 样片接缝与漂移检查 |
| P3 | 数字人口播（TTS + 形象图 + B-roll 混剪） | 30s 口播样片口型/一致性检查 |
| P4 | 风格包/模板库 + 批量变体（营销 AB） | 模板渲染 self-check |

## 6. 主要风险

1. **成本风险**：720p 成片约 1.5–2.1 元/秒，试错同步烧钱 → 强制 480p 草稿先行，UI 前置成本预估。
2. **一致性风险**：多段续接的身份漂移不可完全消除 → 状态台账 + 参考图锁定 + 单段重抽机制；数字人主线混剪形态规避纯连续叙事。
3. **合规风险**：真人形象/音色需授权；AI 生成内容需标识；带货文案受广告法约束（极限词过滤可复用 DeepSeek 校验环节）。
4. **API 变动风险**：Model ID、价格、参数以控制台为准 → 全部做成配置，self-check 覆盖参数校验失败路径。
