# 上传短视频操作教程

每段录屏讲一个操作，通常不超过 5 分钟。发布教程只更新服务器目录，客户不需要重新安装软件。

## 准备录屏

- 视频：MP4，使用 H.264 编码、1080p，文件不超过 256 MiB。超过 5 分钟时按操作拆成几段；页面和服务器都会检查时长。
- 封面：从录屏中选一张能看清操作位置的截图，PNG 或 JPG，建议 16:9，不超过 2 MiB。
- 标题直接写操作，例如“上传本人形象”“选择出镜场景”“把官方素材加入AI混剪”。
- 录制前隐藏客户聊天、手机号、授权信息与密钥；录屏内容面向所有安装用户。

## 上传、预览、发布

1. 在维护电脑的 `desktop/` 运行 `node scripts/open-maintenance-admin.cjs`，浏览器打开 `http://127.0.0.1:18081`，上传期间保持隧道运行。后台只监听服务器回环端口，不新增客户管理入口；沿用已有管理员 SSH 配置，密钥不上传到页面。
2. 滚动到“视频操作教程”，填标题，选“短视频获客 / 微信拓客 / 产品详情图 / 物保素材库”。短视频教程可进一步选“数字人 / AI混剪 / 产品效果视频”，通用步骤选“基础操作”。
3. 选择 MP4 和封面，点击“上传并保存草稿”。页面显示上传进度，可取消上传；失败后重试不会改动已发布教程。
4. 点击“预览”，确认声音、画面、文字大小和拖动进度条都正常，再点击“发布”。草稿不会出现在客户端。
5. 客户打开“操作教程”，或制作页的“看操作演示”，点击“刷新”。选教程后首次会准备视频并校验摘要，随后播放；已准备的视频可以离线重看。

“修改”可改标题、分类，也可换录屏或封面；未重新选文件时保留原文件。保存修改后先回到草稿，检查后再发布。“下架”停止新分发，客户端刷新后移出列表；已有本地视频文件保留。

## 技术边界与部署

- 教程独立于物保素材库：视频不是供混剪使用的官方素材，不进入客户素材索引。
- 管理 API：`GET/POST /api/tutorials`；原始文件流式上传 `POST /api/tutorials/files?kind=video|cover`，必须经过现有回环 Host 与同源 Origin 检查。视频不经过 Base64 JSON 大内存缓冲。
- 客户 API：`GET /v1/tutorials/catalog`、`GET /v1/tutorials/files/{sha256}.{mp4|png|jpg}`。只有已发布记录引用的文件可分发；播放器支持单字节区间 Range 请求。
- 服务数据：`/var/lib/ai-maintenance/tutorials/` 中保留目录 SQLite 和摘要寻址原文件。原文件不自动清理；下架不删除。部署脚本备份目录库，不改写已上传视频；完整异地灾备仍按服务数据备份流程执行。
- 服务程序必须同批部署 `service.py`、`tutorials.py`、`tutorials-admin.js`、`admin.html` 及现有服务文件。更新使用修改后的 `upgrade.sh`，先备份再部署，健康检查包含教程目录。
- 客户主进程使用可信维护服务地址，缓存目录和封面；播放前将视频流式写入专用缓存并核验长度和 SHA-256。renderer 只收到受控播放 URL，不接触密钥或本地文件路径。
- 尚未上传时显示“短教程正在准备中”，并保留文字操作说明入口；不把演示素材伪装成用户操作录屏。
