## 真实素材人工验收

1. 使用 `npm.cmd run desktop` 启动源码开发版。在素材仓库添加真实图片／视频，保存素材集，填写确认过的产品事实和推广目标。
2. 在“其他创作方式 → 商品单片与声音／音乐资源”配置现有配音、音乐资源；在原 API 设置配置百炼。授权音乐和声音必须满足既有使用条件。
3. 向三个区分别放入 2、2、3 个素材，也可留空某一区。试用预览、移除、跨区拖动或下拉移动，确认原文件不移动。
4. 点击 AI 推荐数量，检查建议条数、已找到可用方案数和原因。手填 5 或 6 时不生成全部组合；可行数够时允许高于推荐。输入 50 但素材不足时保留 50，先采用建议或修改数量，再开始制作。
5. 请求 1、2 条应直接完成对应条数；请求 5、6 条先做 3 条样片。看画面与解说的事实、连贯性、节奏和差异，满意后继续；样片计入目标数量。
6. 调整一条的标题、解说或镜头，保存后点击生成样片复核。其他已完成作品不重做。一个口播段落可以对应多个连续镜头；引用顺序必须覆盖所选镜头，实际配音不能超过这组画面的可用时长。
7. 制作中暂停并恢复；也可关闭后重新打开当前批次。已完成作品应保留，未知外部调用不得自动重复扣费。同步接口无法查询时需要人工核对服务记录。
8. 在成片中心按批次预览、导出已完成作品。导出目录包含 MP4、真实画面封面、标题与发布文案 TXT，以及批次清单 JSON；文件缺失应在清单标注。
9. 核对原声静音、AI 解说与字幕对齐、不同对象未拼成虚假效果对比、近重复未计为新增成片。用一批真实素材确认质量后，再扩大实际制作数量。

# 当前规则：自主选材与目标数量

素材是候选池，AI 根据主题自主选取片段、组合顺序与成片时长，不强制每条覆盖全部素材，不固定 60 秒。用户手填数量时围绕该目标规划；留空时先搜索与复核，再推荐数量。首次请求先返回完整方案，展示实际素材数、镜头数、预计时长及完整口播，再点击生成样片开始配音。旧成片保留；重新保存时旧的全素材方案失效并按新规则规划。

新批次保留规划区间的播放时长，配音较短时以留白和音乐承接真实画面；可在连续且观察内容相同的已分析区间内选择更多真实画面，不越过其他已选区间、不循环画面、不加速语音。口播复核包含自然表达、开场与结尾，不能把镜头观察当作结尾。

已通过构建及 12 项服务级检查，覆盖自主选取部分素材、允许超过60秒的合法方案、按手填目标规划、规划与制作分开、配音后区间时长保留，以及原数量/恢复/去重流程。真实 AI 口播质量和批量成片仍需验收，不以模拟结果替代。
