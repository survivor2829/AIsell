# 480p 生成与本地画质处理

## 当前实现

新建的产品效果视频任务与数字人口播样片默认提交 `seedance-2.5` 的 480p 档。源视频和任务记录保留；本地 FFmpeg Lanczos 放大后输出 1080×1920，界面标为“1080p 尺寸·本地放大”。旧任务（包括原社媒短片任务）按创建时的分辨率继续，不重提付费请求。预览生图、人物素材审核、重做镜头、本地处理时间和电费不包含在下表。

| 原始视频时长 | 480p 估算 | 原生 1080p 估算 | 原始视频 API 差额 |
| --- | ---: | ---: | ---: |
| 30 秒 | $2.88 | $11.55 | $8.66 |
| 45 秒 | $4.32 | $17.32 | $13.00 |
| 60 秒 | $5.76 | $23.09 | $17.33 |

按 [APIMart Seedance 2.5 当前价格页](https://apimart.ai/zh/model/doubao-seedance-2-5)的无参考视频预估单价 480p `$0.09608/秒`、1080p `$0.38488/秒`计算。该页说明预扣按分辨率估算，实际按 token 用量结算；界面金额只是估价，需以任务账单为准。

## 开源增强候选

| 方案 | 适合用途 | 取舍 |
| --- | --- | --- |
| [FFmpeg Lanczos](https://ffmpeg.org/ffmpeg-scaler.html) | 当前默认：快速、无需额外模型；统一输出尺寸、保留音频 | 插值放大，不会找回原本不存在的设备细节 |
| [Real-ESRGAN ncnn Vulkan](https://github.com/xinntao/Real-ESRGAN-ncnn-vulkan) | 下一轮优先对比：Windows/Vulkan，支持图片目录输入输出，MIT 许可证 | 视频需拆帧、处理、按原帧率和音频重组；模型可能生成伪纹理或闪烁，不能直接标为“原生1080p” |
| [Video2X](https://github.com/k4yt3x/video2x) | 整段视频处理与 Real-ESRGAN 接入的参考实现 | 需要 Vulkan；项目许可证为 AGPL-3.0，纳入商业桌面发行前要单独审查发布方式和义务 |
| [BasicVSR++](https://github.com/ckkelvinchan/BasicVSR_PlusPlus) | 时序一致性研究候选 | PyTorch/MMEditing 环境较重，暂不适合作为渠道商普通电脑的默认处理器 |

## 进入 AI 增强默认档的条件

用同一张清洁设备图、同一脚本与场景做三版：480p 原片、480p＋Real-ESRGAN、原生 1080p。逐帧检查设备标识和按钮、地面纹理、运动连续性、人物脸与口型；记录本地设备型号、处理耗时、显存、失败率以及实际 API 账单。若增强使产品细节失真或时序闪烁，应保留原片；对比完成后再决定是否增加原生 1080p 重做入口。未完成这项实测前，不对外宣称“效果接近或超过原生1080p”。
