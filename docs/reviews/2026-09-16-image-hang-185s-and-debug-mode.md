## 3. 调试指令（给 Codex）

### M1（最优先）：阶段标记实时落盘，而不是随 stdout 返回

- 每个阶段**开始时**（不是完成时）立即把 `{stage, ts, clipboard_seq}` 追加写入磁盘进度文件（如 `%TEMP%\xiaoxi-image-progress-<trace>.jsonl`）。
- 超时/异常终止后，编排层第一件事读这个文件：最后一条标记 = 挂起点。`failure_stage` 不得再出现 "unknown"。
- 同步在诊断事件里带上 `stage_timings`。

### M2：单联系人图片调试模式（打破"整批跑→导包→等半天"循环）

- 目的：把图片问题的调试迭代从"半天一轮"压到"几分钟一轮"，客户机上几分钟内即可获得多份带标记的证据。

### M3：本机复现工具（把调试从客户机搬回来）

- 复现成功 = 后续调试全程本地进行，客户机只做最终确认。
