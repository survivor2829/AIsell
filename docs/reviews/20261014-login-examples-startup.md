# 登录页、离线成片示例与启动收尾（2026-10-14）

基线：1.1.92 / 3194345，接续 `codex/business-assistant-frame` 当前未提交改动。本轮不提交、不发布、不生成付费内容、不发送微信、不修改其他工作树。正常开发入口仍为 `desktop/` 下 `npm.cmd run desktop`。

## 已实现

- 登录视觉使用用户截图上半部裁剪后的 WebP，真实表单保留保存授权、更换授权、显示/隐藏、忙碌和错误状态。保存授权用固定掩码，不将真实授权码或授权 ID 放入输入框。
- 云端会话初始化不再阻塞主窗口和授权 IPC。两个内容侧车在读取配置和启动前等待最新会话；授权变更仍刷新会话、重启配置消费者。未移除组件签名、迁移、任务恢复和业务就绪检查。
- 增加每进程一次的启动阶段日志。真实诊断系统过滤普通 info，所以显式使用有限的 trace 记录阶段和 elapsed_ms；已从实际候选日志确认落盘。
- 增加两个离线成片、封面、共享播放器和功能映射。主页面横向展示两张卡片，功能页按钮显示“看成片示例”。点击前不加载 MP4；支持原生播放控制、失败重试及教程回退。无示例功能保留教程，统一教程列表不删除。
- 当前 renderer 用户可见“AI混剪”统一为“线索视频混剪”，保留内部路由、任务 ID、历史记录。详情图入口改为“查看生成示例”，保留三组完整长图。

## 发布就绪边界与接续

本轮源码、正常开发入口、文件协议隔离桌面候选及媒体检查已完成，软件保持新登录页打开。尚未运行 CI、合并 main、构建正式增量候选或执行 CD，不把开发/隔离验收写成正式安装验收。

正式内部候选还须按原发布门禁：冻结提交 → 构建包含此前 Python 根因修复的内容运行时（仅界面改动不重建）→ 本机候选验收资源随包、断网播放、正常安装启动 → CI → main → 获准版本的组件增量 CD。本轮复用1.1.92二进制运行时的离线样片验收，不证明此前 Python 修复已经进入交付二进制。

剩余限制：网络不可用时新有效授权激活仍可能等待云会话刷新；`license-auth:logout` API 回调也会等待未结束的云初始化。普通界面“退出登录”仅返回登录页，不清除本地授权，已通过。未声称验证快速更换多个有效授权或 API 注销的最坏等待时长。正式客户付费生图、真实微信与异机验收仍未进行。
