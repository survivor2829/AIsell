# 视频下载、原画面封面与模型费用核查

核查日期：2026-10-22。工作分支：`codex/video-download-cover-audit`。本轮只做本地修改和验证；没有提交、推送、CI/CD、安装更新、服务器部署或新增付费制作。产品详情图不在范围内。

## 本地修改

- 混剪播放器隐藏原生失效下载项，页面统一为“下载视频”，复用已有主进程另存为接口。保存成功显示文件名，取消不报成功，失败和断连可重试；拒绝缺少保存结果的响应。
- 根据随后用户反馈，单作品改为左侧300 CSS px以内竖屏视频、右侧完整文案与下载操作；按结果区实际宽度在680px以下转为上下排列，多作品保留原网格。单作品播放器读取成片首帧，不使用旧课程poster，旧媒体文件不改写。
- 只有新建混剪制作 run 写入 `narrated_original_frame`。其配方使用 `preserve_source` 原画面封面，清空额外视觉事件、关闭额外标题与自动AI封面；正常口播字幕、配音和配乐不移除。共用渲染器仅对该封面标记绕过文字、色块及品牌叠加，并复用已有原镜头定位。
- 旧 run、已有成片和封面不迁移、不重做。成片中心保留原另存为入口，补齐调用异常反馈与保存状态恢复。

截图中的紫色“课程现场价值”来自 `cover.jpg` 的默认课程包装，MP4首帧没有该色块。旧混剪还启动了自动封面任务，但该任务在分析阶段因 `cover_analysis_invalid`（标题缺少口播依据）失败；封面账本仍为planned，没有成功生图回执。主视频completed与封面失败是两个状态。本轮不重试或修改旧任务。

TTS使用当前后付费系统音色价；ASR采用同型号极速识别的公开Coze参考价，不能把新录音识别2.0或预付资源包折扣价直接套给当前`auc_turbo`。[火山语音官方计费](https://docs.volcengine.com/docs/DoubaoVoice/Billinginstructions-21?lang=zh)、[极速识别参考价格](https://docs.volcengine.com/docs/Coze/Built-inintegrationfee?lang=zh)。供应商账单、阶梯折扣、缓存及资源包没有账户级结算证明，1.81元只能称已记录用量的标价估算。

未知事件为 `GatewayReplayRetry`，随后使用同一operation_id／client_request_id返回成功与用量，不算另一笔新制作，也不把未知用量当零费用。关联封面任务消耗约0.106638元的分析／识别估算，失败发生在生图之前，没有成功AI图片回执。

新混剪关闭自动封面分析与生图后会去掉该部分；素材数量、原片总时长和是否复用分析决定其他费用，不能把本次1.81元视为每条固定价，也不能按输出时长直接等比推算全流程。
