# 1.1.16 启动前未读消息复测

上一轮用户已确认自动回复运行后能抓取并回复新消息。本轮仅修正启动时已有红点的消息被当作历史基线跳过的问题。

1. 暂停并退出测试版，覆盖安装后确认版本 **1.1.16**。
2. 在自动回复尚未运行时，由已授权测试联系人发送一至两条新问题，保留未读红点，不手动点开。
3. 启动自动回复，确认这些消息被读取并正常回复；连续问题应保留在本次接待上下文中。
4. 再发送一条新消息，确认运行期间仍可正常接待。随后暂停、重新启动，确认已回复消息不会再次发送回复，已读旧聊天不会被主动翻出补答。

本轮删除仅因“早于启动时间”而屏蔽未读消息的规则；仍保留接待名单、草稿保护、消息身份、已发送与结果不明记录。没有未读标记的旧消息不作为本轮补答范围。

若失败，保留当前微信画面并通过吐槽中心提交反馈。无需为收集日志重复发送同一条消息。
