# 混剪文案细节标准

适用于文案生成、事实复核和已确认稿微调。

- 名称精度与画面证据一致。分不清具体种类时使用可靠的上位称呼，例如“地上的杂物”；不能确定类别时不写这个细节。不猜品牌、材质、数量或效果。
- 按完整段落及全文理解主观烦恼、愿望、条件与假设，不把标点拆开的短语误当成设备效果。第一人称中的实际经历、具体物体和能力声明仍须有依据。
- 文字观察可能漏掉物体或位置；复核同时查看本段对应的原始中心帧。补充观察须记录帧索引、素材时间与镜头事实标识，不能引用别段图片，不把单帧升级为过程结论。
- 在三份备选稿交给用户前应用上述规则，减少确认后的零碎修改。
- 已确认正文不自动改写；修改须有用户授权，并通过原有编辑、确认流程保留旧确认版本。配音和字幕共同使用新确认正文，emoji 仅用于字幕装饰。
- 不因称呼微调重做无关素材分析；缓存复用需与正文、镜头证据及审核规则版本一致。不为通过审核而放宽真实事实要求。
- 小幅改稿保留能够确定对应关系的分句镜头绑定；实际切镜头使用这些分句的 ASR 词边界，不按整个自然段均分跨场景画面。修改跨越原绑定边界、无法可靠映射时不强行继承。
- ASR 少量漏字不应丢弃整段已知时间。正文核对通过后，可用首尾均精确匹配的原词边界展示整句字幕；有差异的句子不显示伪造逐字同步。不能确定边界时仍回退整句/段，不凭字数均摊时间。
- 整体画面复核与生成指令隔离；审核单条稿件不能要求重新提供三个备选，不能将可选逐句字段当成必填。希望、能不能、愿意试用等完整表达按愿望或问题理解，不要求画面证明愿望已经实现；实际清洁效果断言仍须有证据。
- 自动生成阶段的自然段默认分配同一素材文件中的镜头；短素材配短段。确认正文的编排可使用同一已核实活动的跨素材镜头组合，但不得据此声称片段属于连续同一事件。确认正文只调整镜头分配，不自动缩写；容量不足须补充可用真实镜头或提示调整。

本次授权实例：用户先同意把“大厅里的落叶”改为“大厅里的杂物”（第2版），后同意标题改为“我想减轻的，是重复清理的负担”，并将“还有门口的椅子和设备箱”改为“还有旁边的椅子和设备箱”（第3版）。这不代表未来所有已确认稿均可擅自改写。

实现：`SCENE_COPY_GUIDANCE` 用于生成及复核；事实审核使用全文语境并将语境纳入缓存键；`update_candidate` / `confirm_script` 保存修订与确认历史。
